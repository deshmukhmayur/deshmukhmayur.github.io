Shipping a static site on Workers

Workers static assets over Pages: no adapter, unlimited free requests, and one wrangler.jsonc. What I'd tell past me.

Every guide said Pages. Pages was the answer for three years — then Workers static assets quietly grew up, and the migration is one config file you can read aloud.

The whole deploy config

The surprise is that there isn't one: wrangler.jsonc with an assets block, a 404-page (not SPA-fallback — ask me how I know), and routes for the apex plus a www redirect. That's the deploy story.

Free tier: unlimited static requests. The real ceilings are 20k files per version and 25 MiB per file — none of which a personal site will ever touch.
